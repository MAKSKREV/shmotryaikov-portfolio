# @shmotryakov — разработчик

Русская визитка разработчика приложений, сайтов, Telegram-ботов и ИИ-автоматизаций. Ретро-интерфейс Mac, небольшие окна и пассивные анимации без кнопки включения.

[Открыть визитку](https://makskrev.github.io/shmotryaikov-portfolio/) · [Открыть сайт ремонта](https://makskrev.github.io/remont-zelyony-kopiya/)

## Кейсы

- Telegram: PRUstarsbot и парсер объявлений с публикацией в канал через бота. Использованы оригинальные скриншоты.
- ML: работа с техническими чертежами на хакатоне и реальное фото обучения модели. По информации владельца портфолио, этот проект также был продан.
- Сайт компьютерной мастерской: ретро Windows 95/98/XP. Сохранён на главном экране и в кейсах; доступен по прежней ссылке.
- Коммерческий сайт ремонтной компании: услуги, калькулятор стоимости, галереи интерьеров и тарифы. Обозначен как проданный сайт по информации владельца портфолио. Превью и кнопки ведут на опубликованный проект.

Все представленные кейсы помечены как проданные проекты по информации владельца портфолио. Прежний концепт Buffer убран из основной подборки. Сайт компьютерной мастерской остаётся в `projects/website.html` и в основной подборке.

## Запуск

Статический сайт без сборки: `python3 -m http.server 4173 --bind 127.0.0.1`, затем http://127.0.0.1:4173/.

GitHub Pages публикует корень ветки main. index.html и shmotryAIkov.html — одинаковые входные страницы. Изображения, шрифты и иконки лежат в assets.

## Взаимодействие

Окна можно двигать, закрывать, сворачивать и восстанавливать иконкой Mac. Галерея доступна с клавиатуры. Вкладки направлений и Telegram-кейсов поддерживают стрелки, Home и End. Анимации запускаются автоматически; скрытые вкладки и элементы вне экрана приостанавливаются для экономии ресурсов.
